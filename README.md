# 심야식당

일본 골목 끝 작은 식당의 주인이 되는 웹 게임. 요리, 손님 이야기, 가게 성장을 연결하는 첫 플레이 버전입니다.

**플레이:** https://rosagkim.github.io/midnight-diner/

## 플레이 흐름

- 34초의 움직이는 일러스트 프롤로그 → 영업 준비 → 손님 입장·착석.
- 머리 위 음식 말풍선으로 주문 확인 → 냉장고에서 재료 선택 → 조리.
- 재료 정확도와 익힘 정도에 따라 만족도·음식값·팁·평판 변화.
- 자동으로 시작되는 손님 대화에서 주인장 선택 → 평판 → 다음 밤 손님 수.
- 수입으로 재료 보충, 연어 오차즈케 해금, 맡김 차림 선택, 등불·화분 구매.
- 하루 마감 정산, 다음 밤, 자동 저장·재개, 초기화.

첫날은 세 명의 손님입니다. 손님은 천천히 방문하며 시간 초과 페널티는 없습니다. 타이밍 조작이 부담스럽다면 부엌에서 **느긋한 조리**를 켜세요. 인트로는 일시정지·건너뛰기·다시 보기를 지원합니다.

현재 요리 네 종류, 창작 손님 여섯 명, 대화 사건 하나, 가게 장식 두 종류입니다. 맡김 차림은 배운 요리 한 접시를 고르는 형태입니다. 음성·실사 영상·자유 대화 AI·여러 코스 조합은 포함하지 않습니다.

## 실행

패키지 설치나 빌드 없이 실행합니다.

```sh
python3 -m http.server 8000 --directory docs
```

http://localhost:8000 에 접속합니다.

| 파일 | 역할 |
| --- | --- |
| `docs/index.html` | 식당·부엌·이야기·관리·프롤로그 화면 |
| `docs/style.css` | 반응형 UI와 프롤로그·손님 애니메이션 |
| `docs/engine.js` | 재고·경제·조리·손님·평판·저장 검증 규칙 |
| `docs/game.js` | 화면 갱신, 입력, 시간 진행, 저장 |
| `docs/assets/*.svg` | 직접 그린 식당 내·외관 |
| `planning/game-design.md` | 게임 방향, 구현 사양과 후속 범위 |

진행은 해당 브라우저의 localStorage에 저장합니다. 이전 프로토타입 저장은 밤·제공 수를 유지하고 매출을 새 화폐 단위로 환산합니다. 저장을 사용할 수 없으면 화면 하단에 알립니다.

## 검증

Node.js 18 이상에서 외부 테스트 패키지 없이 실행합니다.

```sh
node --test tests/engine.test.cjs
node --check docs/game.js
```

경제·만족도·팁·재료 차감·중복 제공 방지·메뉴 해금·맡김 차림·장식·이벤트·입장·저장 검증·이전 저장 이전·자금 고갈 복구를 확인합니다. 브라우저 검증에서는 인트로 진행, 한 밤 완주, 두 조리 방식, 구매·장식·주문, 저장·초기화 및 모바일 가로 넘침을 확인합니다.
