# 심야식당 PWA

설치해서 실행하는 전체 화면 식당 운영 게임입니다. 웹 주소는 설치 진입점이며, 설치한 앱에서는 **세로형 인트로 → 전체 화면 식당** 순서로 실행됩니다.

**설치 없이 플레이:** https://rosagkim.github.io/midnight-diner/preview.html

**설치 주소:** https://rosagkim.github.io/midnight-diner/

## 실행과 설치

- Android·데스크톱 Chrome/Edge: 설치 주소에서 **앱 설치하기**, 또는 브라우저의 앱 설치 메뉴를 선택합니다.
- iPhone/iPad: Safari의 **공유 → 홈 화면에 추가**로 설치한 뒤 홈 화면 아이콘으로 실행합니다.
- macOS Safari: **파일 → Dock에 추가**로 실행합니다.
- 일반 브라우저에서는 설치 안내를 표시하며 게임은 설치한 앱에서 시작합니다.
- 전체 화면·세로 방향을 우선 요청합니다. 가로 화면도 지원합니다.

앱을 열면 **720×1280 세로형 2.5D 시네마틱 인트로**를 재생합니다. 새로 생성한 실사풍 장면에 고정된 구도에 음식의 김과 부드러운 장면 전환을 합성했습니다. 첫 거리 장면에만 아래로 떨어지는 적당한 비를 추가했으며, 실내 장면에는 비 효과가 없습니다. 확대·축소·카메라 이동·밝기 흔들림은 적용하지 않습니다. 원본 실사 화면은 포함하지 않습니다. 인물이 자유롭게 움직이는 완전한 3D 영상은 아닙니다.

여성 주인장과 **새 일본어 여성 합성 내레이션·새 한국어 자막**으로 구성했습니다. 참고 영상의 화면·음악·녹음·대사를 사용하지 않습니다. 빗소리·주방 소리·잔잔한 배경음은 직접 합성했습니다. 특정 배우의 목소리를 복제하거나 변조하지 않았습니다. 사용 모델과 제작 출처는 [제작 기록](planning/intro-production.md)에 남겼습니다.

기기가 음성 자동 재생을 막으면 무음으로 시작하며 **소리 켜기**로 들을 수 있습니다. 영상 종료나 건너뛰기 후 게임 화면으로 전환합니다.

## 게임 화면

냉장고와 냉동실은 문을 직접 눌러 열고 닫으며, 이번 요리의 재료는 작은 그림·이름과 굵은 체크로 확인합니다. 주요 행동은 두께가 있는 금빛 나무패의 부드러운 두 번 박동으로 표시하고, 영업보고에는 다음 레벨까지 남은 성장 점수와 평판·만족도·분위기 막대를 보여 줍니다. 메뉴명은 단어 중간에서 끊기지 않습니다. 오디오 출처와 적용 범위는 [v24 제작 기록](planning/direct-kitchen-v24.md)에 남겼습니다.

- 식당 장면이 화면 전체를 차지하며, 스크롤하는 페이지·소개 문구·푸터가 없습니다.
- 상단에 밤·시각·자금·평판과 설정, 하단에 냉장고·메뉴·꾸미기·이야기 도구를 배치했습니다.
- 손님을 누르면 하단 대화창에서 얼굴·프로필과 이야기를 보고 주문을 받습니다. 마지막 대사 뒤에 부엌으로 이동하는 버튼이 나타납니다.
- 재료 25점·손질 25점·불 조절 50점으로 평가합니다. 요리와 밤마다 익힘 지점이 다르고 레벨에 따라 판정이 좁아집니다. 활동 중 45초를 넘긴 대기는 만족도 감점으로 이어지며, 마감 때 영업비가 정산됩니다. 손질은 도구를 누르거나 미는 조작으로 진행하고, 불 조절은 약불·중불·강불과 뒤집기, 초록 구간에서 불 끄기로 판정합니다.
- 손님 대화와 주인장 선택은 별도 대화 화면으로 표시됩니다.
- 재료 구매·메뉴 해금·맡김 차림 선택·장식 구매는 해당 도구 화면에서 진행합니다.
- 마감 정산에서 다음 밤으로 넘어갑니다.

한 밤은 3사이클·9명으로 진행합니다. 각 사이클 세 손님의 메뉴는 모두 다르며, 세 손님을 결제·배웅한 뒤 다음 사이클을 시작합니다. 마감 버튼을 누르면 별도 영업보고에서 매출·팁·자금 순증감, 평판·누적 만족도 변화, 성장 점수·레벨·다음 조건과 새 구매 가능 항목을 확인합니다.

10대 후반–70대 손님 얼굴 24종은 기존 머리·옷·인상을 유지한 부드러운 일본 애니메이션풍 이미지입니다. 따뜻한 식당 배경과 어울리는 색감·채색으로 표현합니다. 캐릭터는 연결된 텍스처 메시로 더 또렷한 호흡과 고개·머리카락의 지연 움직임을 부드럽게 표현합니다. 입 모양은 모든 화면에서 원화 그대로 고정합니다. 한 개의 WebGL 렌더러를 공유하고, 지원하지 않는 환경에서는 정적인 원화를 포함한 기본 동작으로 전환합니다. 플레이어가 바 안쪽의 보이지 않는 주인장인 1인칭 구도입니다. 주인장 아바타·손님 하체·의자를 없애고, 바 건너 손님의 상체만 표시합니다. 대사는 손님을 클릭한 상세 화면과 이야기 창에서만 표시합니다. 장면은 좌우로 드래그하거나 화살표로 둘러볼 수 있고 가게 밖 보기로 외관을 꾸밀 수 있습니다. 가게 밖에는 적당한 비가 아래로 내리며, 실내에서는 창틀 사이 유리 너머에만 움직이는 비가 보입니다. 동작 줄이기 설정에서는 비 움직임을 멈춥니다. 손님 대화창은 직업·나이·스타일과 단골 여부를 보여줍니다. 서로 다른 3일 방문부터 단골이며, 만족도 90 이상 손님은 방문 때보다 레벨이 두 단계 오른 뒤 재방문 대상이 되며, 만족도와 관계가 좋을수록 재방문 확률이 높아집니다. 한 밤에는 얼굴이 중복되지 않으며 새 손님을 계속 배정합니다. 24종 얼굴을 순환하는 새 방문자에게는 별도 이름과 방문 기록이 부여됩니다. 단골에게는 조리 전 달걀 곁들임을 한 번 서비스할 수 있습니다.

음식은 모두 다른 이미지가 있는 100종입니다. Lv.1은 3종으로 시작하며 Lv.2–33은 레벨당 새 요리 3종, Lv.34는 마지막 1종이 열립니다. 메뉴 수첩은 전체/현재 가능/레벨별 필터와 이름 검색을 제공하며 미래 메뉴는 흐린 이미지와 해제 레벨로 표시합니다. 다음 레벨에 열리는 음식과 가구의 실제 배치 모습을 미리 볼 수 있습니다. 레벨은 성장 점수·평판·누적 만족도 조건을 모두 달성하면 오르고, 달성한 레벨과 이전 구매는 유지됩니다. 추천 메뉴도 주문 편중을 막는 순환 규칙 안에서 선택됩니다.

꾸미기 14종에는 가구별 전용 위치가 있습니다. 구매하면 해당 매장 안팎으로 시점을 옮기고 놓이는 동작과 빛나는 효과, 배치 장소 안내를 보여줍니다. Lv.20 냉장고는 기존 냉장고 자리만 깨끗한 아이보리 제품으로 교체하며 재료 구매가 10% 할인됩니다. 재료 27종도 식당에 어울리는 별도 그림을 사용하며, 해당 재료를 처음 쓰는 메뉴의 레벨에서 구매와 선택이 열립니다. 이전에 가진 미래 재료는 버리지 않고 잠긴 재고로 유지합니다. 자유 배치는 지원하지 않습니다.

이야기는 6가지 사건을 순환하며 사건당 첫 선택과 후속 선택 두 단계로 진행합니다. 선택에 따라 자금·재료·관계를 사용하거나 얻고, 다음 밤에 답례와 후일담이 도착합니다. 손님 상세 대사는 주문마다 바뀌며 저장 후에도 해당 주문의 대사는 유지됩니다.


응대 순서는 **착석 → 대화·주문 수락 → 부엌 → 재료 선택·조리 → 음식 제공 → 식사 → 결제 → 인사·퇴장**입니다. 부엌은 냉장고·화구·밥솥·작업대를 누를 수 있는 별도 화면입니다. 냉장실과 냉동실 문을 각각 열어 실제 선반에 놓인 재료를 고르고, 부족한 재료는 한 개씩 채울 수 있습니다.

구운 주먹밥은 밥솥 뚜껑 열기 → 적정량 뜨기 → 두 손으로 세모 빚기 → 기름 선택 → 불 조절·뒤집기 → 김 감싸기 → 담음새로 이어집니다. 100종은 주먹밥·달걀·국/전골·면·튀김·차가운 요리·밥 차림·팬 요리의 조리 경로를 공유하되 필요한 재료와 목표 익힘, 완성 그림이 달라집니다. 접시의 음식을 모두 물리적으로 시뮬레이션하는 방식은 아닙니다.

내어놓으면 주문한 손님 앞 바 위에 음식이 놓이고 식사 동작이 이어집니다. 약 9초의 활성 플레이 뒤 별점과 금액이 뜨며, 사용자가 눌러야 자금·만족도·성장이 반영됩니다. 현금이 자금 표시로 날아가며 숫자가 적립되고, 마지막 인사를 마쳐야 자리가 비워집니다. 손으로 빚은 그릇은 기존 찬장 부분을 직접 편집한 배치 이미지로 교체합니다.

## 오프라인과 저장

서비스 워커가 앱 화면·게임 코드·아이콘·인트로 전체를 함께 저장합니다. 설정에서 **오프라인 실행 준비 완료**를 확인한 뒤에는 인터넷 없이 다시 실행하고 영상을 볼 수 있습니다. 영상 탐색을 위한 HTTP 바이트 범위 응답도 지원합니다.

진행은 이 기기의 localStorage v7 키에 저장합니다. v2–v6의 진행을 읽어 자금·구매·메뉴·재고를 유지합니다. 조리 중에는 완료한 단계와 선택 재료를 복구하고 진행 중이던 손동작/불 조절 단계만 다시 시작합니다. 제공·결제 대기·배웅 상태도 저장하며, 이전 버전에서 이미 받은 음식값은 다시 지급하지 않습니다. 다른 기기와 동기화하지 않으며, 운영체제나 사용자가 앱 데이터를 삭제하면 저장도 지워질 수 있습니다.

업데이트는 새 파일들을 모두 저장한 뒤 준비됩니다. 설정의 **새 버전으로 다시 열기**로 진행을 저장하고 전환합니다. 플레이 도중 강제로 새로고침하지 않습니다.

## 로컬 개발

빌드나 게임 실행용 패키지는 필요하지 않습니다.

```sh
python3 -m http.server 8000 --directory docs
```

Chrome/Edge에서 http://localhost:8000 을 열고 앱으로 설치합니다. 서비스 워커는 HTTPS 또는 localhost에서만 동작합니다.

| 파일 | 역할 |
| --- | --- |
| `docs/index.html`, `docs/style.css`, `docs/kitchen.css` | 전체 화면 게임·대화·부엌·설치·영상 화면 |
| `docs/cooking-rules.js`, `docs/kitchen.js` | 조리 경로와 냉장고·도구·불 조절 상호작용 |
| `docs/engine.js` | 재고·경제·조리·손님·평판·저장 검증 |
| `docs/game.js` | 게임 입력·화면·세로 인트로 재생·기기 저장 |
| `docs/morph.js` | 호흡·머리카락의 연속 메시 모핑·공유 WebGL 렌더러 |
| `docs/scene.js` | 캐릭터 동작·말풍선·매장 이동·장식 배치 |
| `docs/pwa.js` | 설치·앱 실행 구분과 업데이트 |
| `docs/manifest.webmanifest` | 앱 이름·아이콘·전체 화면·가로 방향·범위 |
| `docs/sw.js` | 오프라인 앱 저장과 영상 바이트 범위 응답 |
| `docs/assets/opening-portrait.mp4` | 새 실사풍 세로 시네마틱, 새 여성 내레이션·직접 합성한 사운드·새 자막 포함 |
| `planning/game-design.md` | 게임 방향과 구현 범위 |

## 검증과 배포

```sh
node --test tests/*.test.cjs
node --check docs/game.js
node --check docs/pwa.js
node --check docs/sw.js
```

규칙·모핑 연속성·오프라인 영상 응답 테스트 총 26개를 실행합니다. 브라우저에서는 설치 진입 화면, 앱 표시 모드에서의 실행, 실사 재생·종료 전환, 주문·조리·구매, 세로·가로 화면, 오프라인 재실행과 저장 재개를 검사합니다.

항상 같은 메인 주소 **https://rosagkim.github.io/midnight-diner/** 에 업데이트를 적용합니다. 버전별 별도 주소를 만들지 않습니다. 설치 없는 미리보기도 고정 주소 `preview.html`을 사용합니다. GitHub Pages는 `main`의 `/docs`를 제공합니다. 검증 후 `main`에 푸시합니다. 앱 파일 변경 시 `docs/sw.js`의 `VERSION`도 바꿔 기존 설치 앱에 업데이트를 전달해야 합니다. 모든 자산 경로와 PWA 범위는 저장소 하위 경로를 지원합니다.

재료 화면은 품절과 조리 중 잠금을 구분합니다. 품절 재료는 주문 화면에서 바로 채울 수 있고, 필수 재료를 모두 고르기 전에는 시작 버튼에 아직 필요한 재료 이름을 보여줍니다. 새 시작에는 종이등이 없으며, 구매 시 중앙에 하나만 설치됩니다. 음식 이미지는 각 칸 여백을 넓힌 버전과 표시 경계 클리핑으로 옆 음식 조각이 섞이지 않게 표시합니다.


현재 조리 화면은 작은 조리 아틀라스를 교체해 재료 손질 22종×4상태, 공용 동작 8종×4상태, 가열 메뉴 91종×3상태를 512–627px 크기의 장면으로 표시합니다. 밥솥·빈 그릇·한/두/세 주걱과 흩어진 밥→둥근 덩어리→세모의 변화가 실제 진행과 대응합니다. 밥이 필요한 메뉴는 밥솥부터 시작하며, 날음식·소금 주먹밥은 굽지 않고 볶음면에 국수 건지기 단계가 나오지 않습니다. 완성·서빙에는 기존 메뉴 그림을 유지하고, 식후에는 같은 그릇에 잔여물이 남은 그림을 표시합니다.

첫 화구 사용에서는 다이얼 회전 시범과 실제 익힘 막대로 연습합니다. 불을 끄면 익힘 점수와 만족도·팁의 관계를 보여주며, 재료·돈·진행을 소모하지 않고 다시 연습할 수 있습니다. 음식 위로 미는 표시는 제거했고 실제 굽기의 뒤집기는 명시적인 도구 버튼으로 합니다. 여성 주인장의 손은 화면 아래에서 들어오며, 이야기의 인물은 원래 3:4 비율을 유지하고 배경·테두리를 표시하지 않습니다.

메인 준비 화면에서 예상 3끼/9끼에 부족한 재료만 합산해 한 번에 채울 수 있습니다. 영업 시작 레벨의 메뉴로 그날의 주문을 구성하므로 미리 산 재료와 주문이 맞고, 새 레벨의 메뉴는 다음 개장부터 주문됩니다. 첫날에는 Lv.1 아홉 끼를 만들 수 있는 기본 재료가 들어 있습니다. ‘식당 불 켜기’ 전에는 실제 조명이 꺼진 그림을 보여주고, 누르면 조명이 켜진 뒤 첫 손님이 들어옵니다. 다음 날 준비에도 같은 흐름을 적용합니다.

v19는 사용자 요청에 따라 이전 플레이를 초기화하는 새 v10 저장으로 시작합니다. 첫 진입에서 이전 v1–v9 키를 정리하며, 이후 새 플레이는 자동 저장되어 재접속해도 유지됩니다. 엔진의 레거시 가져오기 기능은 별도로 유지합니다. 승인된 인트로 영상과 음성은 변경하지 않았습니다.

v19 매장은 장식·종이등 없는 조촐한 낡은 실내와 입구에서 시작합니다. 장식은 배경과 함께 그린 선반·작업대·문 앞의 표면을 교체합니다. 구매한 아이템이 중앙에서 커지고 실제 자리로 날아가 안착하며, 해당 부분에 반짝임과 분위기 증가량이 표시됩니다. 구매한 등도 개장 전에는 꺼져 있습니다. 분위기는 성장·평판·만족도와 함께 레벨업 조건에 들어가며, 이미 얻은 레벨은 유지됩니다.

냉장고·재료 구매에는 수량 조절과 한 번에 채우기가 있습니다. 선택한 필수 재료를 다시 누르면 재고를 1개 추가하며, 재료 보관 화면의 사진을 반복 눌러도 바로 보충됩니다. 3끼 준비를 선택하면 9끼 버튼은 사라지고, 명시적으로 준비량을 다시 고를 때만 표시됩니다. 칼은 이미 잡은 상태로 시작하며 밥 한 주걱부터 여성의 손과 주걱이 보입니다.

영업보고는 큰 성장 수치, 초록색 상승·빨간색 지출/하락, 실제 결제한 손님의 마지막 리뷰 네 개, 금고 내역과 다음 조건으로 나뉩니다. 다음 레벨은 큰 네모 배지로 표시하고, 음식과 아이템 보상은 각각 이미지로 보여 줍니다. 아이템에는 분위기 증가량이 표시됩니다. Web Audio로 직접 합성한 칼질·따르기·밥 뜨기·볶는 소리·계산대 효과음이 동작하며 설정에서 끌 수 있습니다.


v20에서는 현재 v10 플레이를 v11로 그대로 옮기며 다시 초기화하지 않습니다. 상점·보상·구매 연출은 배치되는 원본 그림의 같은 물건을 보여 줍니다. 꾸미기는 15자리×4모음의 60종이며 같은 자리의 다른 모양으로 교체하거나 보유한 물건을 무료로 다시 배치할 수 있습니다. 조명은 최대 3개를 고르며 각 천장 자리에 따로 설치됩니다. 1개만 설치하면 작은 조명 하나만큼의 온기만 더해집니다. 카운터 앞면과 찻장 등 큰 면도 바뀌어 완성된 매장의 변화가 보입니다. 모음 5/10종 보너스와 개별 팁·기다림·할인 혜택은 실제 계산에 적용됩니다.

새 요리 이미지는 초기 5종(구운 주먹밥·다시 달걀말이·돼지고기 된장국·연어 오차즈케·파 달걀부침)에만 우선 적용합니다. 탄 표면·졸아든 국물의 추가 그림을 실제 열량에 맞춰 겹쳐 전환합니다. 나머지 음식의 이미지는 사용자 승인 전까지 기존 상태를 유지합니다. 불 세기에 따라 끓는 표면·수증기와 소리가 달라지며 설익거나 과열된 완성 음식은 같은 원래 그릇의 별도 모습으로 손님에게 나갑니다. 정상 완성품은 기존 그림입니다. 된장은 스푼으로 뜨고, 다시는 액체를 따르며 각각 다른 소리를 사용합니다. 식사 완료는 메인 화면 손님의 결제 표시를 빛내며 조리를 가리는 안내는 나오지 않습니다.

이야기는 기기에 설치된 한국어 음성으로 읽고 현재 화자의 말풍선만 강조합니다. 일시정지·다시 듣기가 있으며, 한국어 음성이 없는 브라우저에는 읽을 수 있는 안내를 표시합니다. 음성 합성은 승인된 인트로와 분리되어 있으며 앱에서 별도 TTS API를 호출하지 않습니다. 브라우저가 제공하는 음성의 연결 방식은 기기 설정을 따릅니다.

검증에는 규칙 테스트 62개와 320/393/430px 모바일 플레이 검사를 사용했습니다. 조명 다중 설치·동일한 상품 그림·된장/다시 조작·과열 음식 제공·조리 중 결제 알림·기존 v10 저장의 실제 가져오기를 확인했고, 오프라인 자산과 영상 범위 응답도 검사했습니다. 자동 브라우저의 운영체제에는 한국어 음성이 없어 실제 발화 대신 음성 이벤트 어댑터로 순서·화자 강조·중지와 다른 손님 이벤트 중 지속을 검증했고, 음성 없는 기기의 대체 안내도 확인했습니다.

앞으로 요리 관련 이미지 수정은 반드시 위 초기 5종만 먼저 생성·수정·적용해 미리 보여주고, 명시적인 사용자 승인을 받은 후에만 다른 음식으로 확대합니다. 전체를 미리 생성하지 않습니다. 이 규칙은 이번 v20 배포에도 적용하며 나머지는 기존 이미지를 사용합니다.


v21은 기존 v11 플레이를 유지합니다. 주요 UI를 월넛 나무판과 따뜻한 한지 질감으로 바꾸고, 짧은 제목에는 로컬 나눔손글씨 붓 폰트, 본문과 숫자에는 선명한 인쇄 글씨를 사용합니다. 폰트와 재질 이미지는 오프라인에서도 표시됩니다. [폰트 출처와 라이선스](planning/ui-font-v21.md)를 기록했습니다.

손님은 처음에는 이름·직업·나이가 알려지지 않습니다. 인사하고 질문하거나 손님의 질문에 답하면서 알게 된 정보가 저장되고, 다음 방문에도 기억됩니다. 대화 선택지에 따라 주문으로 바로 넘어가거나 이야기를 더 들을 수 있으며, ‘잠시 자리로’는 대화 패널 안에 있습니다. 주문 수락·조리·계산·작별 흐름과 기존 저장은 유지합니다.

모핑은 손님별로 다른 확률의 고개 돌림·어깨 정돈·머리카락 움직임을 연속적으로 섞습니다. 화구의 수증기와 구매한 조명 주변의 작은 빛 입자가 더 잘 보이며, 개장 전에는 꺼져 있고 동작 줄이기 설정을 따릅니다. 요리 이미지는 이번 작업에서 변경하지 않았습니다.

시간대 변화도 같은 게임 시계를 따릅니다. 영업은 00:30에 시작해 조리·대화 중에도 시간이 흐르고, 깊은 밤에는 골목이 어두워지다가 동틀 무렵 창문과 골목에 푸른 아침빛이 들어옵니다. 기존 골목등은 새벽에 꺼집니다. 활동 중인 시간만 저장하며, 시계 때문에 강제로 폐점하지 않습니다. 다음 밤 준비에는 다시 불이 꺼진 매장으로 돌아갑니다.

조리 효과음은 물·달걀물·기름·된장·가루의 질감을 구분하는 새 합성 모델을 사용합니다. 비·실내 공기·멀리 지나가는 차, 실제 입장에 맞춘 미닫이문과 발걸음, 식사 중 작은 식기 소리와 조용한 먹는 소리를 더했습니다. 환경음과 게임 전체 소리를 따로 설정할 수 있고, 인트로·앱 백그라운드에서는 환경음이 멈춥니다. 외부 녹음은 사용하지 않았으며 승인된 인트로 음원은 유지합니다.

종이 패널은 실제 섬유와 얕은 주름·눌린 결이 드러나도록 질감을 보강했습니다. 주요 외곽에는 모서리 이음과 두께가 보이는 나무 프레임을 사용하고, 선택지는 들린 종이 쪽지, 주요 조작은 결이 있는 나무패로 표현합니다. 클릭·비활성·키보드 초점은 구분되며, 실제 물건 아이콘에도 글자 라벨을 유지합니다.

이번 v21은 규칙·저장·오디오·모핑·시간대·PWA 테스트76개와320/393/430px 브라우저 검사를 통과했습니다. 실제 선택지→재접속→주문·조리→수금·배웅, 물/된장/달걀물의 소리 경로, 실제 식사 중 식기 소리, 어둠→새벽·골목등 소등, 오프라인 폰트·전체 자산과 영상 범위 응답을 확인했습니다. 소리 출력과 음량·파형은 검증했지만 이 실행 환경은 오디오 입력을 지원하지 않아 주관적인 직접 청취 검증은 하지 못했습니다. [오디오 제작·검증 기록](planning/audio-materials-v21.md), [나무 프레임](planning/ui-frames-v21.md), [사물 아이콘](planning/ui-icons-v21.md), [아날로그 조작 요소](planning/ui-controls-v21.md)를 기록했습니다.

v22는 지속 배경음을 제거해 조리하지 않을 때 조용합니다. 액체·끓임은 출처가 확인된 CC0 효과음 파일로 교체하고, 조작이 끝난 뒤 따르기 소리가 중복 재생되지 않게 했습니다. 완성에는 짧은 벨 소리가 한 번 납니다. 대화는 주인장 이름표와 손님 캐릭터 옆 말풍선으로 구분하고 작은 발견 문구·식사 전 추가 이야기·부엌 둘러보기 버튼을 제거했습니다. 부엌 표찰·명조 글꼴·금빛 다음 버튼과 첨부 장면의 밤 배경도 적용했습니다. [음원·글꼴·이미지 출처와 범위](planning/quiet-service-v22.md).

v23는 영업 진행을 작은 종이 표찰로 줄이고 이야기 안내를 두 줄로 정리합니다. UI 글꼴을 명조체로 통일하고 큰 제목을 줄였으며, 이야기 음성과 듣기 버튼을 제거했습니다. 냉장고의 필요한 재료는 그림 카드로 먼저 보여 주고 보충 조작은 작게 배치합니다. 냉장고 표찰·진행 중인 요리에만 금빛 안내를 주고, 끝난 이야기의 강조는 해제합니다. 된장은 왼쪽 통에서 오른쪽 빈 그릇으로 한 번 옮기면 완료되고 실제 다음 단계로 진행됩니다. [수정 내용·무료 음원 출처·검증](planning/service-clarity-v23.md).


v25는 초록색 빈 영역을 없애고 조리 화면에 가스레인지 전체와 실제 조작 다이얼을 함께 표시합니다. 카운터·부엌·가게 밖을 오가며 진행 중인 조리를 유지하고, 손님 이름은 처음 도착할 때부터 표시합니다. 꾸미기 안내는 한지와 나무 재질로, 이야기 알림은 작은 촛불로 바꾸었습니다. 완성음의 높은 소리와 날카로운 시작을 줄였습니다. 기존 v11 저장을 유지하며 85개 규칙 테스트와 모바일·오프라인 검증을 통과했습니다. [변경·출처·검증](planning/full-scene-v25.md).


v26은 손님 아래 명패를 작은 가로형 상태패로 바꾸고, 주문 준비 완료일 때만 금빛 테두리와 가벼운 두근거림을 표시합니다. 음식과 명패 사이 간격, 인물 가운데 정렬, 작은 이동 메뉴와 열쇠 위치, 남은 성장 점수 표시를 조정했습니다. 첫 냉장고 문 안내는 한 번 열면 사라지며, 재료 보충은 같은 재료를 다시 눌러1개씩 합니다. 화면 아래 초록 여백과 조리 배경 중첩을 없애고 화구 아래 불꽃을 작고 부드럽게 바꿨습니다. [변경·검증](planning/service-guidance-v26.md).


v27은 한 조의 첫 손님은 즉시, 나머지 두 손님은 메뉴를 고른 뒤 차례로 주문 준비 완료가 됩니다. 조리 화면의 재료 목록·동작 다시 보기와 모든 밥 메뉴의 밥솥 열기를 제거했습니다. 작업 사진이 여백 없이 채워지고, 밥알 질감과 화구 양옆 불꽃을 조정했습니다. 완성음은 초기 알림음으로 되돌리고 수금음 등 효과음 음량을 맞췄습니다. 기존 조리 저장은 단계 삭제에 맞춰 이어집니다. [변경·그림 출처·음량·검증](planning/staggered-orders-v27.md).


v28은 사용자가 승인한 중앙 팬·중앙 다이얼 하나의 넓은 화구 배경과 도마 작업대를 **레벨1–5의15개 메뉴에만** 적용합니다. 음식의 덜 익음·알맞음·탐을 조리·담기·완성·서빙에 연결하고 밥알은 사용자 사진을 기준으로 낱알 형태로 다시 그렸습니다. 조리 보조·재생 버튼과 불꽃은 제거하고, 안내 문구·작은 알림등·보고서·레벨 표기를 정리했습니다. 설정에서 조용한 오리지널 배경 음악의 켜기·끄기·볼륨을 따로 저장할 수 있습니다. [제작·범위·검증](planning/approved-stove-v28.md).


v29는 조리 준비 제목을 도마의 여유 있는 아래쪽 위치로 내리고 긴 조작 설명을 제거합니다. 달걀물 붓기는 팬만 도마 위에 놓이며 메인 상단 두 패널의 왼쪽 선을 맞춥니다. 배경음악은 무료 사용곡 **Minamo — PeriTune(CC BY4.0)**로 교체하고 설정에 출처·라이선스를 표시했습니다. 기존 음악 설정과 저장 진행을 유지합니다. [변경·음원 출처·검증](planning/clear-preparation-v29.md).
