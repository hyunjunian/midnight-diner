# 세로 인트로 제작 기록

- 기준일: 2026-11-07
- 최종 요청: 실제처럼 보이는 모바일 세로 애니메이션, 여성 주인장과 여성 목소리의 일치, 참고 작품의 영상·녹음·음악·대사를 사용하지 않는 새 구성.

## 화면

- 새로 생성한 실사풍 키프레임 네 장을 [스토리보드](assets/intro-storyboard.png)에 보관한다.
- 2026-11-07 로컬 식당 수정: 외관 자체를 일본 골목 식당의 목재 미닫이문·격자창·목재/회벽 외장으로 바꾼다. 내부 출입문·창호도 같은 건축 양식으로 통일한다. 소품 추가만으로 끝내지 않으며, 기존의 따뜻한 밝기·여성 주인장·음식·네 카메라 구도를 유지한다.
- 여성 주인장, 올리브빛 목재 창호, 직사각 목재 미닫이문과 노렌, 살구빛 회벽과 오래된 목재 외장, 호두나무 카운터가 있는 새 식당이다. 특정 배우나 원작 캐릭터 외형을 재현하지 않았다.
- 장면: 비 오는 골목 → 김이 오르는 냄비 → 주방에서 준비하는 여성 주인장 → 한 사람을 위한 밥상.
- 720×1280, 9:16, 24fps, 약 34초.
- 고정 구도에 음식의 김·장면 디졸브를 합성한 **2.5D 시네마틱 애니메이션**이다. 인물 동작을 연속 생성한 AI 영상이나 완전한 3D 캐릭터 애니메이션은 아니다.
- 2026-11-07 수정: 네 장면 모두 구도를 고정했다. 1·3번째 장면의 합성 비와 모든 장면의 확대·축소·좌우 이동·밝기 변화 효과를 제거했다. 2·4번째 장면은 국물의 김만 움직인다.
- 재제작 소스: [영상 렌더러](../tools/render-intro.py). 기존 AAC 오디오는 재인코딩하지 않고 그대로 복사한다.
- 현재 도구에는 인물 동작을 생성하는 전용 영상 모델이 없다.
- 원본 드라마/사용자 제공 동영상의 프레임·원본 자막 이미지를 사용하지 않는다.
- 이미지 생성: OpenAI 이미지 생성 도구. 생성 프롬프트는 특정 작품·배우·캐릭터의 복제 없이 새 공간과 인물을 지정했다.

## 새 음성과 대본

- 일본어 여성 합성 음성, 한국어 자막으로 구성한다.
- Kokoro-82M 기본 여성 음성 `jf_alpha`로 새 일본어 대본을 합성한다. 참고 배우의 음성을 입력·학습·복제·변조하지 않는다.
- 공식 모델 카드의 모델 이용 조건은 Apache 2.0이며, 일본어 음성 목록에서 `jf_alpha`가 여성 음성으로 안내되어 있다.
- 도구·모델의 이용 조건과 생성 오디오의 권리 보장을 혼동하지 않는다. 법적 위험이 전혀 없다는 절대적 보장은 하지 않는다.

| 시작 | 일본어 내레이션 | 한국어 자막 |
| --- | --- | --- |
| 1.0초 | 雨の夜は、少しだけ、ゆっくり支度をします。 | 비 오는 밤엔, 조금 천천히 준비해요. |
| 9.25초 | 湯気が上がると、この小さな店も目を覚ます。 | 김이 오르면, 작은 가게도 잠에서 깨요. |
| 17.5초 | 話したくない日は、何も言わずに座っていてください。 | 말하고 싶지 않은 날엔, 그냥 앉아 있어도 괜찮아요. |
| 25.8초 | いらっしゃい。あなたの席を、ひとつ空けておきました。 | 어서 와요. 당신 자리는 하나 비워 두었어요. |

대본과 자막은 이번 게임을 위해 새로 작성했다. [자막 원본](assets/intro-captions.ass)을 함께 관리한다.

## 새 사운드

- 빗소리·낙숫물·국물 끓는 소리·그릇 소리는 노이즈와 감쇠 공명을 조합해 직접 합성한다.
- 배경음은 직접 합성한 드문드문한 건반/벨 계열 음과 잔향이다. 기존 곡이나 샘플 라이브러리를 쓰지 않는다.
- 제작 소스: [사운드 생성 스크립트](../tools/generate-intro-soundscape.py). NumPy·SciPy는 제작 시에만 필요하며 PWA 런타임에는 필요하지 않다.
- 앞선 요청에 따라 시험했던 원본 음성 분리·변조 결과는 **배포하지 않는다**. 현재 인트로에 원본 음악·녹음·대사는 포함하지 않는다.

## 도구·라이선스 출처

- [Kokoro 공식 모델 카드](https://huggingface.co/hexgrad/Kokoro-82M): Apache-2.0, 모델 이용 안내.
- [Kokoro 음성 목록](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md): `jf_alpha`, Japanese female.
- [Kokoro 코드](https://github.com/hexgrad/kokoro), [Apache 2.0 사본](licenses/Kokoro-Apache-2.0.txt).
- [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx), [MIT 사본](licenses/kokoro-onnx-MIT.txt).
- 모델·ONNX 런타임·사전은 제작 환경에만 설치한다. 앱에는 렌더링한 영상·오디오만 포함한다.

## 앱과 배포

- 앱 매니페스트와 전체 화면 방향 요청은 portrait다.
- 현재 영상은 `opening-portrait.mp4`다. 이전 `opening.mp4` 실사 클립과 포스터는 현재 배포 자산에서 제거한다.
- 서비스 워커 캐시 버전을 올린다. 기존 앱은 설정에서 새 버전으로 재실행해야 한다.
- 앱 범위·저장 데이터·설치 방식·게임 규칙은 유지한다.
