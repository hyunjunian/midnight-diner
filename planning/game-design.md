# 심야식당 — 게임 방향과 첫 플레이 버전

- 기준일: 2026-11-07
- 방향: 사용자가 설명한 요리·경영·손님 이야기 중심의 작은 일본 골목 식당
- 상태: 방향을 플레이로 확인하기 위한 첫 구현. 수치, 이야기, 미술은 이후 조정한다.

## 플레이어가 느낄 것

바쁜 주문 처리보다 **내가 차린 한 끼가 누군가의 밤을 바꾸고, 그 기억으로 식당이 자라는 경험**을 중심에 둔다. 아기자기한 인물, 나무 카운터, 청록색 노렌, 주황빛 조명으로 일본의 작은 골목 식당을 표현한다.

## 핵심 순환

프롤로그 → 영업 준비 → 손님 입장·착석 → 머리 위 음식 말풍선으로 주문 확인 → 냉장고 재료 선택 → 조리 → 만족도·음식값·팁 → 손님 대화와 주인장의 선택 → 마감 → 재료 보충·요리 해금·식당 꾸미기 → 다음 밤.

## 인트로 연출

사용자가 제공한 MP4의 첫 34초를 이미지 프레임으로 확인했다. 참고 구간의 핵심 흐름은 카운터를 닦는 주인장 → 메뉴판 → 가게 밖에서 노렌 걸기 → 시계다. 도시·골목 전경으로 시작한다고 가정했던 임시안은 폐기했다.

게임은 이 흐름을 새 SVG·CSS 애니메이션으로 재구성한다. 독백은 제공된 영상의 내용을 바탕으로 한국어 문장을 조정했다. 원본 영상, 음악, 배우의 외형은 포함하지 않는다. 유사한 구성과 문장에 관한 권리 문제가 없다고 보장하는 것은 아니다.

| 시간(게임 내) | 화면 | 독백 내용 |
| --- | --- | --- |
| 0:00–0:08.8 | 주인장이 카운터를 닦는다 | 사람들이 귀가할 무렵 식당의 하루가 시작된다 |
| 0:08.8–0:11.5 | 나무 벽의 메뉴판 | 단출한 메뉴 소개 |
| 0:11.5–0:19.8 | 식당 외관, 노렌을 걸어 올린다 | 재료가 있고 만들 수 있으면 주문을 받는다 |
| 0:19.8–0:28.8 | 등불이 켜진 식당 | 자정부터 아침 일곱 시, 심야식당이라는 이름 |
| 0:28.8–0:31.5 | 문 앞 노렌 | 늦은 시간 손님이 오는지 묻는다 |
| 0:31.5–0:34 | 벽시계와 라디오 | 생각보다 많은 손님이 찾아온다 |

첫 방문에 자동 진행하며, 일시정지·다음 장면·건너뛰기·다시 보기를 지원한다. 모션 감소 설정에서는 정지 상태로 시작한다. 현재는 영상 파일과 음성이 아닌 움직이는 일러스트와 자막이다.

## 이번 버전에 구현한 규칙

### 손님과 영업

- 카운터 세 자리. 손님은 약 6.5초 간격으로 도착하며 빈자리가 없으면 기다린다.
- 첫날 세 명, 개점 시 평판 25마다 한 명 추가, 최대 여섯 명.
- 손님의 음식 말풍선을 누르면 이름, 사정, 주문, 필요한 재료가 부엌에 보인다.
- 식사 후 약 12초에 퇴장한다. 진행 중인 대화 이벤트가 있으면 기다린다.
- 기다림 패널티, 오프라인 시간 진행, 식재료 부패는 적용하지 않는다.
- 모든 손님에게 제공하고 이벤트에 응답하면 마감할 수 있다.
- 표시되는 시각은 실제 타이머가 아닌 영업 진행도다.

### 요리와 만족도

- 기본 메뉴: 구운 주먹밥, 다시 달걀말이, 돼지고기 된장국.
- 추가 메뉴: 연어 오차즈케. 자금 ¥900으로 배운다.
- 재료 선택 정확도 60점 + 조리 익힘 정도 40점. 잘못 넣은 재료는 재료 점수를 깎는다.
- 조리는 약 5초. 65% 지점이 최적이며 초록 구간에서 높은 점수를 받는다.
- 느긋한 조리는 시간 제한 없이 슬라이더로 익힘 정도를 정한다.
- 재료는 실제 제공 시 차감한다. 조리 중 새로고침하면 주문은 유지되고 재료는 차감되지 않는다.
- 메뉴 가격의 60~100%를 음식값으로 받으며, 만족도 60점 초과분에 따라 팁이 붙는다.
- 팁 = 메뉴 가격 × max(0, 만족도 − 60) / 100 × 0.65. 만점에서 약 26%.
- 평판 변화: 85점 이상 +4, 65점 이상 +2, 40점 이상 −1, 그 미만 −4.

### 경영과 성장

- 초기 자금 ¥3,200, 기본 재료가 들어 있는 냉장고로 시작한다.
- 재료를 한 개씩 구매한다. 영업 중에도 가능하다.
- 배운 메뉴 중 오늘의 맡김 차림을 고른다. 두 번째 밤부터 추천을 부탁하는 손님에게 실제로 제공한다.
- 맡김 차림은 이번 버전에서 기존 레시피 한 접시를 추천하는 형태다. 여러 코스·자유 레시피 조합은 후속 범위다.
- 따뜻한 등불 ¥1,600: 식당에 표시되며 만족도 +5.
- 골목의 초록 ¥2,200: 식당에 화분이 생기며 매일 첫 손님 입장 시 평판 +2.
- 자금을 모두 쓰고 주문 재료도 없는 경우, 냉장고에서 이웃 상인의 도움을 받을 수 있다. 부족한 재료를 받고 평판 −3. 처음부터 다시 시작하지 않아도 된다.

### 이야기

- 첫 두 손님이 만나면 자동으로 짧은 대화를 시작한다.
- 주인장이 이야기를 들어 주면 평판 +5, 대화를 막으면 −3.
- 결과는 그날의 기억으로 남으며 평판은 다음 밤 방문 인원에 반영된다.
- 현재는 두 손님의 짧은 사건 하나다. 자유로운 대화 AI나 장기 관계 시뮬레이션은 아니다.
- 손님 이름·사정·사건은 창작한 임시 콘텐츠다.

### 저장과 배포

- 브라우저 localStorage에 자금·재고·주문·평판·해금·장식·이벤트를 저장한다.
- 다른 기기와의 동기화는 없다. 저장 불가 상태는 화면에 알린다.
- 이전 버전의 밤·제공 수를 유지하고, 이전 매출은 10원당 ¥1로 환산해 새 초기 운영 자금에 더한다.
- GitHub Pages: `main`의 `/docs`, 상대 경로 자산, 빌드와 외부 런타임 의존성 없음.

## 다음 개발 단계

1. **요리별 손맛:** 주먹밥 굽기, 달걀말이 접기, 국 간 맞추기를 서로 다른 조작으로 구분.
2. **손님에 대한 기억:** 선호 메뉴, 재방문 대사, 관계도, 여러 밤에 걸친 창작 사연.
3. **식당 운영의 깊이:** 발주, 재고 보관, 계절 메뉴, 좌석·조리 도구 확장과 비용.
4. **나만의 맡김 차림:** 여러 코스 구성, 조합 평가, 단골 취향에 맞춘 추천.
5. **평판과 유입:** 음식·분위기·응대 평판을 나누고 입소문·소개 방문으로 표현.
6. **연출:** 더 자연스러운 입장·착석·노렌 동작, 직접 제작한 환경음·조리음·내레이션.

장기 목표는 사용자 요청이다. 위 단계의 순서와 상세 수치는 개발 제안이며 최종 확정 사양으로 보지 않는다.
