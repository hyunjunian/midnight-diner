# v48 첨부 여섯 조리 화면의 국소 수정

## 적용 범위

사용자가 제공한 화면의 지정 부분만 수정한다. 본편 배경/문구/글꼴/메뉴/재고/가격/점수/저장 구조, 실제 화구·다이얼 및 완성 요리 이미지는 바꾸지 않는다. 감자 된장국과 연어 솥밥은 사용자가 해당 화면을 명시적으로 수정 요청한 범위이며, 다른 음식 이미지의 추가 생산 허가는 아니다.

| 화면 | 반영 내용 |
| --- | --- |
| 국물 붓기 | 왼손/왼 소매를 제거하고 가려졌던 나무만 복원. 원래 오른손/팔, 냄비/컵/물줄기/네 진행 상태는 유지 |
| 감자 된장국 담기 | 몸통/음식/그릇/국자를 유지하고 손잡이만 분리해 왼쪽 접합부로 이동·회전. 손잡이 자체는 한 번에 강체 변환. 원본 오른손 하나가 잡음. 확장된 투명 소스와 overflow로 손잡이 끝을 임의로 흐리거나 자르지 않음 |
| 밥 담기 | 기존 오른손/팔만 접점 중심으로 균일135% 확대. 주걱과 실제 포인터 기준점은 그대로. 받는 그릇 네 상태만10소스 픽셀(393px 화면에서 약7px) 아래로 이동 |
| 연어 솥밥 담기 | 음식 부분은 직전 화구의 실제 단계별 조리 이미지를 사용. 받는 그릇은 원래 완성 이미지의 도기와 뚜껑을 그대로 쓰고 내부만 비움. 원래 주걱과 화면 배치는 유지 |
| 달걀 깨기 | 중성색 유리 내부의 실제alpha만 낮춰 현재 도마가 투과함. 원본RGB와 따뜻한 색의 달걀·껍데기는 유지. 테두리/반사 유지. 손이 가리는 부분은 투명 처리하지 않음 |
| 달걀물 붓기 | 컵을 원래대로 유지하고 팬 몸통을 넓혀 중간 측벽의 좌우가 평행하도록 행 단위 원근을 교정. 빈 팬/붓기/채움 네 상태 유지. 같은 원본 오른손/팔 하나를 추가. 가이드 끝도 팬 내부에 맞춤 |

## 자산과 연결

- 원본 v47 자산을 작업용 별도 복사본에서 읽고, 조리/유리/손 등 지정된 마스크만 바꿔 최종lossless WebP를 만든다.
- 오른손은 원래 국물 붓기의 오른손/팔 원화를 분리해 사용한다. 새 전신 인물이나 왼손을 생성하지 않는다. 공통 인디고 작은 꽃무늬 소매 유지.
- `rice-right-hand-v48.webp`는 주걱과 분리된 확대 오른손으로, 주걱이 커지거나 포인터 기준점이 바뀌지 않게 했다.
- `potato-right-grip-v48.webp`와 `pour-right-hand-v48.webp`는 768×1024의 투명 여유 공간을 사용한다. 기존512×768 조리 사진과 같은 좌표계를 유지하며 그 바깥으로 손잡이/소매가 이어질 수 있다. 그라데이션 손목/손잡이 마스크는 없다.
- 국물 왼손 제거와 가려진 나무 복원은 OpenAI image_gen `exec-53bceef4-0ce2-435c-ba8f-bd83f716d685.png`에서 필요한 나무 구간만 가져왔고, 원본 오른손과 나머지 물체는 원본을 보존했다.
- 연어 솥밥 빈 도기의 내부는 원래 완성 그릇을 편집한 `exec-ef11271f-f915-4899-9954-71cd60dfe7fc.png`에서 필요한 내부만 합성했다. 실제 완성 이미지 파일은 수정하지 않았다.
- 릴리스 `20261109-v48-scoped-cooking`: 사전 캐시 목록373개와 각SHA256를 일괄 갱신했다. 기존 v11 진행은 초기화하지 않는다.

## 검증

- 규칙/저장/제스처/오프라인/영상byte-range 테스트123개 통과.
- 320×568,393×852,430×932,852×393에서 여섯 장면24건을 실행해 실제 국물2회/밥2회/달걀 깨기/달걀물 붓기 완료, 오른손 레이어, 확장 소스의 마스크 없음, 유리 네 상태alpha를 확인했다.
- 유리 영역 검사 위치에 손이 가려지는 한 프레임은 불투명해야 하므로, 모든 단계에서 실제 유리인 상단 벽 위치로 검사한다. 손/음식을 투명 처리하는 식으로 테스트를 맞추지 않는다.
- 기존 유리/밥 담기 회귀 검사도 통과: 검정·흰색 실제 배경을 바꿨을 때 유리가 투과하며 음식/팬은 불투명하다. 320/393/430px에서 마우스와 실제 CDP 터치 입력으로 주걱 끝 좌표 일치, 세 번 담기, 소매의 viewport 밖 연속성을 확인했다.
