# v44 · 전체 화면 도마 한 장

## 원인과 수정

v43은 투명 그림의 연결을 다섯 메뉴에만 제한했다. 같은 돼지고기 손질이나 밥 담기도 돼지고기 덮밥을 선택하면 예전의 도마 포함 그림으로 돌아갔다. 그 결과 전체 화면 도마 위에 작은 두 번째 도마가 생겼고, 예전의 잘린 손 그림도 다시 나타났다.

공용 재료 손질·계량·밥 담기·달걀 풀기/붓기·국물·김 작업은 메뉴나 레벨에 관계없이 같은 투명 원본을 사용하도록 수정했다. 고유 음식의v39 전용 사진 연결은 기존 다섯 메뉴를 유지한다. 다른 재료와 서빙 원본54개는 음식/그릇/필요 도구를 유지하며 배경·주변 장식·기존에 구워 넣어진 손을 제거했다. 재료를 써는 손은 공통의 연속된 남색 소매 원본으로 별도 렌더링한다.

조리 중 도마를 그리는 요소는 전체 화면 크기의`#kitchen-screen` 하나다. 다른 장면 요소는 투명하다. 사진의 사각형 가장자리를 흐려서 가리는 방식은 사용하지 않는다. 투명한 사진과 가이드/입력은 같은 좌표 변환을 사용한다. 인트로·저장 형식·경제·승인된 제목 위치는 바꾸지 않는다.

상태패와 진행 버튼 등의 과한 금빛 번짐을 제거한다.2px의 차분한 황동색 선을 갈색 테두리 바깥에 두고, 그림자·필터·확대·이동 애니메이션 없이 유지한다. 결제 영수증은v43에서 복구한 이전 모습을 유지한다.

## 출처와 범위

사용자는 여러 메뉴의 화면을 제시하며 배경 전체를 하나로 수정하도록 명시적으로 요청했다. 기존 그림에서 배경만 분리하는 작업이며 새로운 메뉴나 음식 디자인을 제작하지 않는다. 기존 원본은 이전Git 커밋과 작업용 백업에 보존했다. OpenAI image_gen의 RGBA 결과를 높은 화질의WebP로 인코딩하며alpha는 유지한다. 생성 원본과 검사 결과는`background-cutouts-v44.json`에 기록한다. 별도의 법적 권리를 보장하지 않는다.

## 완료 기준

-100개 메뉴의 모든 비가열 단계가 실제alpha가 있는 파일을 사용해야 한다. 각 아틀라스의 네 칸을 검사한다.
-320/393/430px에서 돼지고기 덮밥의 돼지고기 썰기와 밥 담기를 실제 조작한다. 도마 요소는 정확히 한 개이며 화면 전체 크기여야 한다.
-빈 영역을 사진 레이어 표시/숨김 전후에 픽셀 비교해 두 번째 배경이 없음을 확인한다. 칼질 중 소매 끝이 화면 안에서 잘리지 않아야 한다.
-기존 전체 메뉴 화면·저장/오프라인/릴리스 무결성과 조리 동작 테스트를 통과한 후 업로드한다.
