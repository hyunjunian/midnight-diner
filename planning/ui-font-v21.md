# v21 UI font provenance

`docs/assets/fonts/nanum-brush-script.woff2` is losslessly WOFF2-compressed Nanum Brush Script, Copyright © 2010 NHN Corporation. Downloaded from the official Google Fonts repository (`ofl/nanumbrushscript/NanumBrushScript-Regular.ttf`) on 2026-11-08. It retains its internal names and glyph outlines. CSS may refer to the font with the local alias `DinerBrush`.

Source: https://github.com/google/fonts/tree/main/ofl/nanumbrushscript

License: SIL Open Font License 1.1, included in `docs/assets/fonts/OFL-NanumBrushScript.txt`. Used for headings and selected hand-lettered labels; body copy and numeric controls use readable print fonts. The local font is precached for offline use. No third-party font request occurs at game runtime.
