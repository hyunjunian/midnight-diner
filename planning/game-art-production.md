- `docs/assets/characters-animated.webp`: 같은 도구로 기존 창작 캐릭터를 일본 애니메이션풍으로 다시 그린 창작 성인 7명(손님 6명·여성 주인장). 4열 2행 아틀라스의 마지막 칸은 비어 있다. 배우의 사진이나 실존 인물의 초상을 제공하지 않았다. 주인장은 기존 창작 인트로의 단발 웨이브·올리브색 셔츠·리넨 앞치마와 일치시켰다. 사용자 요청에 따라 실사 같은 피부·머리카락 질감을 간결한 선과 부드러운 채색으로 바꿨으며 기존 인물의 나이·머리·옷·포즈를 유지했다. 가게 배경과 인트로 영상은 이 변경에서 수정하지 않았다.
- 새 아틀라스는 실제 알파 투명도를 포함한다. 화면에서 밝은 색을 지우던 SVG 색상 필터를 제거했다. 머리·몸·팔을 잘라 겹치는 대신 캐릭터 한 장을 그대로 그려 호흡·대화 몸짓·조리 기울임을 움직이며 입 모양만 별도로 표시한다. 손님 화면 갱신에서도 기존 캐릭터 DOM을 재사용하여 다시 생성하지 않는다. 조리 중 클릭을 막을 때도 캐릭터의 불투명도를 유지하고, 첫 화면에서 아틀라스를 미리 불러온다. 3D 모델이나 완전한 얼굴 모션 캡처는 아니다.
- `docs/assets/intro-world.webp`: 승인된 창작 인트로 스토리보드를 WebP로 인코딩한 텍스처. CSS가 첫 외관 장면을 선택한다. 인트로 MP4·음성·자막은 이번 게임 확장에서 변경하지 않았다.
- 장식 8종의 SVG는 프로젝트에서 새로 작성한 도형이다. 매장 안/밖 정해진 위치에 합성한다.
- 생성 도구는 모델 ID·별도 모델 라이선스를 응답에 제공하지 않았다. 생성 결과는 서비스에 적용되는 OpenAI 사용 조건을 따른다. 독점성이나 법적 무분쟁을 보증하지 않는다.

## 현재 규칙

레벨 조건(누적 성장 점수 / 평판 / 누적 만족도): Lv.1 0/0/0, Lv.2 450/25/70, Lv.3 1500/45/80, Lv.4 3200/65/85, Lv.5 5500/80/90. 세 조건을 모두 충족하면 레벨이 올라가며 이미 달성한 레벨은 내려가지 않는다. 누적 성장 점수는 제공한 음식의 만족도 합계다. 메뉴·장식은 자격 해제 후 별도 비용을 낸다.

기존 v2 저장의 자금·재고·구매·진행 손님을 유지한다. 새 만족도·성장 누적 기록은 이전 식사당 70점을 기준으로 이관하며 방문 기록은 이후부터 축적한다. 마감된 기존 3명 영업은 다음 준비 상태로 이관하고, 진행 중인 영업은 목표를 9명으로 확장한다. 이 버전까지는 기존 저장 키를 유지했다. 아래 v4 업데이트에서는 이전 앱이 새 저장을 덮어쓰지 않도록 저장 키를 분리했다.


## 연속 모핑·매장 배치·다양한 손님 업데이트

- `visitors-a.webp`, `visitors-b.webp`: OpenAI image generation 도구로 새로 그린 서로 다른 얼굴 24종. 4열 3행 투명 아틀라스 2장. 19–76세, 얼굴형·눈매·코·주름·머리·작업복을 구분했다. 주인장은 승인된 기존 그림을 유지한다. 같은 도구의 상업 이용 조건을 적용하며 별도 모델 ID는 제공받지 않았다.
- `seated-legs.webp`: 같은 도구로 그린 앉은 하체 4종(바지·치마·신발), 2열 2행 투명 아틀라스. 가게 이미지의 세 의자 중심 26.7%·52%·76.8%와 좌판 높이에 맞춰 상체 아래에 연결한다.
- `decor-real.webp`: 같은 도구로 새로 생성한 등불·화분·도자기 선반·노렌·분재·벤치·찻장·간판 8종. SVG 아이콘을 대신하는 따뜻한 조명의 사실적인 재질 이미지. 문 앞 화분은 입구 옆 바닥, 분재는 카운터, 찻장은 벽 쪽에 배치하고 접촉 그림자를 합성한다. 등불은 기존 천장 조명 위치와 맞춘다.
- `food-painted.webp`: 같은 도구로 새로 그린 재료 7종과 완성 음식 7종. 김은 실제 구운 김, 다시는 육수, 된장은 페이스트, 연어는 필레 형태로 구분했다. 이모지를 대신한다.
- 모핑: `morph.js`는 32×48 연결 메시의 어깨·가슴 호흡, 머리 회전, 지연된 머리카락, 턱, 손 부근 변형을 연속적인 가중치로 계산한다. 이미지 조각을 잘라 움직이지 않는다. 한글 음절의 모음을 분류하여 입의 너비·개방·둥글기를 보간하며, 원화의 입 부분은 피부색으로 부드럽게 블렌딩한다. 실제 음성 녹음과의 립싱크는 아니다. 대사가 표시되는 상세 화면과 이야기 창에서만 손님이 말한다.
- 모든 인물은 공유 WebGL 컨텍스트 1개에서 그려 2D 캔버스에 전달한다. 30fps 상한, 화면에 보이는 인물만 처리, 동작 줄이기 설정 및 WebGL 미지원·컨텍스트 손실 시 원화 폴백을 지원한다.
- 저장은 v4로 이관한다. v2·v3의 자금·재고·구매·기존 손님을 유지하며, 기존 만족도 기록은 그대로 보존한다. 새 방문자 일련번호와 한 밤의 방문 목록을 저장한다. 기존 v2 저장 키를 읽어 이관한 뒤 v4 전용 키에 저장하여, 아직 업데이트하지 않은 앱이 새 진행을 덮어쓰지 않게 한다. 90점 이상 손님은 만족한 방문 시점의 레벨 +2 이후 재방문하며, 한 밤에는 같은 얼굴을 다시 배정하지 않는다. 기본 얼굴 24종을 사용하는 새 방문자는 다른 이름·별도 방문 기록을 갖는다. 최대 레벨에서도 새 방문자를 계속 생성하므로 재방문 대기 때문에 영업이 멈추지 않는다.

## 난이도 조정

손질과 불 조절은 각각 별도 판정이다. 재료 25점, 손질 25점, 불 조절 50점. 요리별 익힘 지점이 다르고 레벨이 오르면 허용 오차가 줄어든다. 필수 재료가 빠지거나 엉뚱한 재료를 넣으면 점수 상한이 크게 내려간다. 활동 중 45초 이후 대기는 최대 20점 감점되며 앱이 숨겨진 시간은 진행하지 않는다. 영업비는 개점 시 레벨 기준 `650 + 250 × 레벨`이며 마감 시 한 번 정산한다. 잔액을 초과해 차감하지 않는다. 느긋한 조리 옵션은 손질·익힘을 직접 조절할 수 있게 유지한다.


## 2026-11-08 · 플레이어 시점과 조리 안내 수정

- `restaurant-counter.webp`: 기존 식당 그림을 OpenAI image generation 도구로 수정해 앞쪽 의자 세 개만 제거하고 바와 조명·부엌을 유지했다. 플레이어는 화면에 보이지 않는 주인장이며 손님은 예전 주인장과 같은 바 뒤 위치에 상체만 배치한다. 원본 그림의 바 하단을 전경 레이어로 덮어 몸이 테이블 앞으로 나오지 않게 한다. 하체 레이어는 생성하지 않는다.
- `food-clean.webp`: 같은 도구로 기존 음식 그림의 칸별 여백을 넓히고 경계의 다른 음식 조각을 제거했다. 표시에서도 3% 안전 여백을 잘라 검은 선·접시 파편이 섞이지 않게 한다.
- 모든 화면의 입 모양 오버레이, 입 셰이더, 턱 개폐 변형과 음절 스케줄러를 제거했다. 현재 모핑은 호흡·머리·머리카락의 미세한 움직임만 유지하며 말할 때도 원화의 입을 변경하지 않는다.
- 중앙 등은 그림 속 기존 등 하나만 사용한다. 등불 구매는 추가 이미지 대신 기존 조명 밝기·온기 보강과 만족도 효과로 반영한다.
- 재료 선택에는 품절/조리 중 잠금 이유와 필수 재료 상태를 표시한다. 부족한 재료는 주문 화면에서 바로 구매 후 선택할 수 있고, 자금이 부족하면 기존 이웃 도움 기능을 해당 화면에 표시한다. 시작 버튼은 아직 선택하지 않은 필수 재료를 안내한다.
