# v47 요청별 수정 시안 (본편 미적용)

사용자가 달걀 깨기 투명도와 달걀물 붓기 팬/드래그의 수정 시안을 요청했다. 이어 밥통 확대, 오차즈케 담기 전 빈 그릇/화살표, 국물 냄비 몸통 확대/손잡이 축소를 지정했다. `docs/mockups/v47/`은 이 다섯 요청의 독립된 확인 페이지와 실제 게임 DOM을 사용한 393×852(2배 렌더링) 캡처다. 기존 게임 JS/CSS/사진/배경/배포 버전에는 변경이 없다.

- egg: 원본 색상/모양을 유지하고 유리 벽 alpha만 낮춤. 쌀그릇의 투과 수준(alpha 약 28–40)에 맞추되 반사와 테두리를 남김. 식품 영역 보호.
- pour: 컵은 원본, 팬 부분만 폭 약 30% 확대/평행한 측면. 화면의 드래그 시작·끝이 모두 팬 내부.
- rice: 기존 밥통 레이어만 15% 확대, 받는 그릇과 손의 크기는 유지. 실제 3회 담기 완료 상태로 캡처.
- plating: 기존 그릇 내부에만 빈 도자기 바닥 합성. 위 냄비/국자/배경은 원본. 시작을 냄비 음식 중앙으로, 끝을 빈 그릇 안으로 이동.
- broth: 냄비 몸통 확대, 손잡이 축소. 원본 계량컵 영역과 게임 배경/텍스트 유지.

기존 승인 사진을 OpenAI image_gen으로 편집했으며, 필요한 부위만 원본에 합성하여 시안을 렌더링했다. 생성 원본: egg `exec-56a69d6e-6fad-4579-9f8c-bef5a9a93d55.png`, pour `exec-3b76e57d-2766-47c5-a390-e60405fb59d1.png`, plating `exec-e987ab62-7aba-4eb2-92eb-d09f5502d88f.png`, broth `exec-62a33102-81a9-4cb7-a83d-f33b7212eb1c.png`.

시안 확인 뒤 실제 연결·동작 판정과 각 단계의 내용물 전환을 구현/검증해야 한다. 정지 시안의 화살표 변경이 아직 본편의 입력 판정 변경을 의미하지 않는다. 기존 게임의 사전 캐시 파일을 변경하지 않았으므로 앱 릴리스를 올리지 않는다.

## 사용자 후속 교정

- 국물 붓기: 몸통 지름을 유지하고 깊이만 줄였으며, 안내선 시작점을 위로 올려 길이를 늘렸다. 원래 계량컵·손·소매·문구를 유지했다.
- 밥 담기: 밥통만 선명하게 보정하고 겹치는 부분에서 밥그릇이 앞에 오도록 했다. 나머지 그릇·손·주걱·UI는 원본이다.
- 오차즈케 담기 전: 새로 그린 냄비를 폐기하고, 실제 `stove-v28-ochazuke.webp`의 마지막 정상 가열 프레임(좌하단)을 그대로 잘라 동일한 냄비와 음식으로 사용했다. 빈 서빙 그릇은 실제 완성 렌더러가 쓰는 `final-v28-ochazuke.webp` 첫 프레임 원본 외형·무늬에 빈 내부만 합성했다. 국자·가이드·문구는 유지한다.
- 편집된 생성 결과를 전체 화면에 대입하지 않고 원본 캡처의 물체 영역에만 합성했다. 가려졌던 도마는 기존 `workbench-v33.webp`를 동일한 393×852/2배 CSS cover 방식으로 복원했으며, 노출된 배경의 RGB가 원본과 일치함을 확인했다. 밥통·냄비 수정은 합성 마스크 바깥 변경 픽셀 0개를 확인했다.
- 생성 출처: 밥통 `exec-6bf90799-d0ee-44cc-918f-4fb2e0ed2929.png`, 얕은 냄비 `exec-20ca2b98-96e3-4f35-b6eb-f583f8ebd66b.png`, 빈 완성 그릇 내부 `exec-9c9fc043-4575-4608-9723-b696e09f458c.png` (OpenAI image_gen). 냄비·완성 그릇 전체를 다시 그린 `exec-c23187aa-cc05-4bd8-85f6-b51bfb07cbf9.png`는 사용하지 않았다.
- 본편 조리 로직·자산·배포 릴리스는 변경하지 않았다. 이 수정은 기존 독립 시안만 교체한다.

## 손잡이 방향 시안 선택 확정

사용자가 두 기준 중 “위에서 보여준, 냄비 손잡이가 왼쪽 아래로 보이는 시안”을 명시적으로 선택했다. 따라서 앞 절의 직전 가열 프레임 재사용 지시를 이번 시안에서는 해당 선택으로 대체한다. `exec-c23187aa-cc05-4bd8-85f6-b51bfb07cbf9.png`의 냄비·음식·왼쪽 아래 손잡이를 사용하며, 현재 빈 완성 그릇과 배경·문구·국자·가이드는 유지한다. 원본 냄비 흔적과 직사각형으로 잘린 아래 경계를 제거했고, 냄비 교체 영역 바깥의 변경 픽셀이 0개임을 검사했다. 확인 페이지의 해당 이미지 캐시 태그만 correction=3으로 갱신했다. 본편은 변경하지 않았다.

## 김가루·손잡이 두 항목만 후속 수정

사용자가 담기 전 김가루를 금지하고 손잡이 길이 보정을 요청했다. 현재 시안의 냄비 몸통·배경·그릇·국자·글자·버튼·가이드는 유지하고, 김가루 영역의 밥·연어·국물과 손잡이만 수정했다. 실제 화구 원본 손잡이의 형태를 사용하되 사용자가 요청한 긴 비율로 조정했으며 왼쪽 아래 방향을 유지했다. 음식 패치 출처는 OpenAI image_gen `exec-8b603d6c-2f04-4694-9113-a1abda48b4b4.png`이며, 생성본의 화구·다이얼·배경은 사용하지 않았다. 화구/다이얼의 기존 본편 파일은 수정하지 않았다. 두 수정 영역 밖의 픽셀은 수정 직전 시안과 바이트 단위로 동일함을 검사했다. 이미지 캐시 태그는 correction=4다.
