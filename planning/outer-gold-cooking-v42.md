# v42 · 바깥 금빛 띠와 조리 위치 고정

사용자는 시안 확인 후 다른 수정사항까지 반영하도록 승인했다. 시안을 만드는 동안에는 게임 소스와 배포를 바꾸지 않았고, 승인 이후에만 이 변경을 반영했다.

## 화면

- 금빛 띠는 완성된 갈색 테두리 바깥에 둔다. 기본 테두리는 갈색3px, 외부 링은4px이며, `inset:-9px`로 갈색 테두리와 분리한다. 광량은 링 외부의 그림자로 만든다. 버튼과 글자를 확대·이동하거나 글자에 광택을 중첩하지 않는다.
- 적용 범위: 영업 시작/마감, 손님 대화의 다음 동작, 보고서의 다음 밤, 조리 진행/서빙, 재료 준비, 기존 이어하기 표찰, 손님 주문 준비 상태패, 결제 영수증, 다음 작업대 표찰, 냉장고의 필요한 문 손잡이. 비활성 버튼·완료된 주문에는 링을 표시하지 않는다. 붉은 알림등은 그대로 유지한다. 결제 영수증은 외부 링만 부드럽게 빛나며 동작 줄이기에서는 멈춘다.
- 냉장고 전체를 감싸던 과거 트레이스는 제거하고 실제 문 손잡이만 강조한다.
- 조리 위치는 `MidnightCookingLayout.workspace`에서 계산한다. 393×852에서 단계 표기 위쪽은170px, 실제 제목 상단은 약195px이다. 높은 안전영역이나 짧은 화면에서는 이동 메뉴 아래 여유를 우선한다. 음식 크기·단계가 달라도 제목 위치는 같다. 완성 제목도 같은 기준이다. 가로 화면은 기존의 왼쪽 조작/오른쪽 음식 배치를 유지한다.
- 서빙은 화면 하단의 불필요한 예약 공간을 줄여 음식·접시를 키운다. 음식과 도구를 별도로 늘이거나 찌그러뜨리지 않는다. 파 달걀부침은 원본 자체에서 잘렸던 팬 손잡이를 온전하게 복원했다.
- 달걀물 붓기는 예전의 유리 그릇과 사각 팬, 눈에 보이는 달걀물 줄기가 있는 네 단계 구도로 복원한다. 검토한 복원 시안에 따라 바탕을 분리하고 손잡이 끝을 온전하게 표시했다. 모든 동작은 하나의 고정 도마 위에서 진행하며 그림/가이드/입력의 좌표 변환을 공유한다.

## 이미지 출처와 범위

기존 승인 그림을 OpenAI image_gen으로 편집했다. 새 메뉴 사진으로 범위를 확장하지 않았다. RGBA PNG를 무손실 WebP로 인코딩했으며 생성 원본은 보존했다.

두 파일은1024×1536의2×2 아틀라스이며 각 프레임은2:3이다. 붓기 파일의 예전1:2 확장 소매 좌표를 재사용하지 않는다. 새 그림은 기존의 승인된 다섯 요리 경로에서만 사용한다. 인트로, 나머지 요리 사진, 게임 경제/저장 형식과 음원은 바꾸지 않는다. 별도의 법적 권리 보장은 하지 않는다.

## 검증

규칙/저장/오프라인 무결성 테스트와 브라우저에서 실제 동작을 검증한다. 금빛 위치·비활성 해제·주문/결제/손잡이 상태, 320/393/430px의 제목 고정, 실제 붓기 중간 프레임/완료/재실행 복구를 회귀 검증한다. 기존 조리 화면 전체와 가로 화면, 안전영역, 투명 원본 비율·칼 소매, 대화/종이 재질과 오프라인 미디어 범위 응답도 확인한다.

실행 결과: Node 테스트120개 통과. 브라우저에서100개 메뉴의673개 손질/가열/완성 상태, 320×568·393×734·393×852(안전영역 포함)·430×932·852×393 배치 통과. 승인된 다섯 요리의27개 준비/옮기기 장면과20종 투명 원본, 실제 된장/다시 동작·칼질, 대화와 종이 재질, 새 금빛/붓기 회귀 검증 통과. 기존v34에서 자동 업데이트 후 저장된 자금·완성 요리 유지, 최신 셸의 오프라인 재실행과MP4/MP3 byte-range 응답도 통과했다.
