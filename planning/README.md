# 심야식당 게임 기획 문서

게임 기획과 참고 조사를 관리하는 폴더입니다. GitHub Pages 배포 소스인 `/docs`와 구분해 관리합니다.

## 문서 목록

| 문서 | 용도 | 상태 |
| --- | --- | --- |
| [원작 조사](research/original-work.md) | 작품 설정, 주요 인물, 음식, 매체 구분, 출처 및 조사 한계 | 공개 웹 자료 조사 |

## 관리 원칙

- 원작에서 확인한 사실, 영상판의 설정, 게임화 해석을 구분합니다.
- 사실에는 출처를 남기고, 미확인 내용은 확정된 설정으로 사용하지 않습니다.
- 게임화 제안은 합의되기 전까지 제안 상태로 관리합니다.
- 새 기획 문서를 추가하면 이 목록에도 링크를 추가합니다.

아직 핵심 플레이 비중, 아트 스타일, 상세 시스템은 결정하지 않았습니다.
