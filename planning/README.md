## 관리 원칙

- 원작에서 확인한 사실, 영상판의 설정, 게임화 해석을 구분합니다.
- 사실에는 출처를 남기고, 미확인 내용은 확정된 설정으로 사용하지 않습니다.
- 게임화 제안은 합의되기 전까지 제안 상태로 관리합니다.
- 새 기획 문서를 추가하면 이 목록에도 링크를 추가합니다.

요리·경영·손님 이야기를 연결하는 첫 플레이 버전을 구현했습니다. 상세 수치와 후속 개발 순서는 조정할 수 있습니다.

- [v48 첨부 조리 화면 국소 수정](scoped-cooking-v48.md): 오른손·손잡이·밥 담기 크기·완성 그릇 일치·유리 투명도·평행한 팬과 검증.
