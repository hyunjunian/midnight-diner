# v43 · 실제 화면 오류 수정

사용자가 보낸 실제 화면의 문제를 함께 수정한다.

- 주문 준비 상태패의 금빛 띠가 위로 벌어진 원인은 기존44px 터치용`::after`의 고정 높이와`translateY(-50%)`가 남았기 때문이다. 금빛은`::before`로 분리하고 높이·너비·패딩·변환을 명시적으로 초기화했다. 투명 터치 영역은44px을 유지한다. 두 개의 준비 상태패와 결제 손님 한 명이 함께 있는 상황에서 위치·글자·클릭을 확인한다.
- 결제 영수증은 사용자 요청대로v42 이전 스타일로 되돌린다. 영수증을v42의 갈색3px 테두리·큰 금빛 링·링 애니메이션 대상에서 모두 제외했다. 종이 영수증과 원래 결제 대기 효과는 유지한다.
- 두부 손질 원본에 남아 있던 도마 배경을 제거한다. 사용자가 지적한 두부 원본만 투명하게 편집했으며, 화면의 고정 도마는 그대로 한 장만 렌더링한다. 새 메뉴 촬영 범위를 확장하지 않는다.
- 완성 음식의 목표 중심을세로 화면60%에서56%로 올리고, 음식명과 주문자 문구를24px 올린다. 짧은 화면에서는 제목과 겹치지 않도록 기존 범위 제한을 유지한다. 조리 중 제목은v42 승인 위치 그대로다.
- 김 접기는 별도`fold`제스처로 왼쪽에서 중앙으로 한 번만 받는다. 펼친 김→접는 중→한 번 접힌 반쪽으로 보여 주며 네 번째의 더 좁은 그림으로 진행하지 않는다. 완료 후에는 추가 입력을 받지 않는다.
- 밥 담기는 왼손을 없애고 밥솥을 위쪽, 같은 그릇을 아래쪽에 둔다. 오른손의 맨팔은 짧게 하고 소매는 바깥으로 이어지게 한다. 세 번 담는 수량과 그림은 유지하며 안내선은 실제 밥솥과 낮아진 그릇을 연결한다.
- 김 두르기의 정상 주먹밥은 원본 타일의가로55.6%에 있다. 그 실물 중심이 화면 중앙에 오도록 공통 좌표 변환에`focusX`를 추가했다. 그림만 따로 이동하지 않으며 가이드와 입력도 함께 이동한다.

## 검증

`tests/browser/scene-repairs.cjs`는320/393/430px에서 두 준비 손님과 결제 손님의 실제 화면, 링의 실제 외곽 크기/위치와 텍스트 포함 여부,44px 터치 동작, 두부 빈 영역의alpha=0, 완성 음식/텍스트 위치, 단 한 번 김 접기와 추가 입력 차단,0→1→2→3주걱, 주먹밥 실물의 가로 중심을 확인한다. 결제 영수증 스타일은v42 CSS를 제외한 기준과 직접 비교한다.

기존 규칙·저장·서비스 워커 무결성 테스트, 다섯 요리 조리 화면·동작, 짧은/긴/가로 화면 검증도 함께 실행한다. 저장 형식과 게임 경제, 승인 인트로는 수정하지 않는다.
