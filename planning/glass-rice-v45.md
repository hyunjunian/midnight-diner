# v45 · 투명 유리와 실제 밥 담기 동작

사용자가 달걀 풀기 그릇과 붓기 컵의 불투명한 내부, 밥 담기의 남은 배경/잘린 소매/움직이지 않는 손, 준비량 버튼 밑줄을 지적했다.

유리 용기는 겉 테두리·반사와 음식은 유지하고 빈 내부가 실제alpha로 현재 도마를 투과하도록 수정했다. 단순히 사진 전체의 불투명도를 낮추거나 기존 도마를 그릇 안에 구워 넣지 않는다. 달걀 풀기와 붓기 네 단계 모두 유리 내부 표본alpha를 검사하고, 실제 화면의 배경을 검정/흰색으로 바꿔 내부가 그 변화에 반응하는지 확인한다. 음식/팬 표본은alpha245이상으로 유지한다.

밥솥/그릇 아틀라스에서 손·주걱·배경을 모두 분리했다. 그릇의0/1/2/3주걱은 기존 단계대로 유지한다. 별도의 연속된 오른손/주걱이 실제pointerdown/move/up을 따라 움직이며, 밥솥에서 시작해 그릇에 놓는 유효 동작일 때만 수량을 올린다. 도구의 같은 손 자세를 유지하고 주걱 머리 부분만 쌀이 있는 그림으로 전환한다. 소매는 화면 밖까지 이어지며 취소·이탈·완료 때 떠 있는 쌀을 남기지 않는다. 제목 위치와 저장 형식은 유지한다.

`glass-rice-v45.css`는 새 도구 레이어와 준비량 다시 고르기의`text-decoration:none`만 추가한다. 전체 도마는 계속`#kitchen-screen`하나에서 그린다.

## 검증

`tests/browser/glass-rice.cjs`는 모든 유리 단계의alpha, 배경을 바꾼 실제 픽셀 투과, 음식/팬 불투명도, 밥 담기 사진 아래쪽의 넓은 빈 영역, 실제pointer와 주걱 끝 좌표 일치, 세 번의 개별 담기, 화면 밖 소매, 버튼 밑줄 제거를320/393/430px에서 확인한다. 기존 전체 원본 연결/도마 한 장/조리 동작과 저장·오프라인/릴리스 검사도 실행한다.
