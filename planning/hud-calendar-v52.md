# HUD, shelf stock and calendar

- Analog clock uses the authoritative MidnightDaylight game minutes, white enamel dial, black hands, recessed walnut opening; retains accessible exact time.
- Funds/reputation plaques open read-only detail sheets. Preparation shows current funds without incorrectly reusing the previous night's revenue; opening resets the existing ledger normally.
- The night plaque opens a paper calendar with service/events/records views and 28-night pages. No real-world start date has been invented. Existing storyMemory, nightNews and pendingConsequences provide actual story history and known follow-ups; viewing does not resolve choices, mark stories read, spend funds or advance time. New settled reports are archived on closing and persist in optional calendarRecords, capped at 1000 reports. Legacy saves remain valid; missing historical totals are explicitly labelled rather than reconstructed.
- Five affinity hearts show the existing per-person 0–20 saved affinity, including partial hearts. No relationship rules changed. The speech tail is a single small triangle instead of a rotated square.
- Kitchen rain and dawn grading are clipped to individually authored glass panes and projected through the same cover crop as the room/hit targets. Counter and kitchen use the same rainy setting and daylight clock. No indoor rain or new ambient sound.
- Ingredient storage artwork: 27 raw ingredient/container side views generated with OpenAI image generation in this session, transparent 6×5 sprite sheet `/workspace/generated_images/exec-2e1ade9c-2706-446c-9f14-0bcd758ed8ed.png`; source preserved. Uniform cell extraction/encoding produces fridge-side-*-v51.webp. Only refrigerator stock appearance changed; recipe art, preparation, completion and menu identities remain intact.
- Calendar paper: original blank paper and brass-ring background generated with OpenAI image generation in this session, source `/workspace/generated_images/exec-048bd46c-a095-48ad-b85d-a4052349032d.png`; source preserved, WebP copy used. - Removed three unused image preloads that caused console warnings. Runtime verification uses normal service-worker-enabled Chromium, not blocked-worker test warnings.
