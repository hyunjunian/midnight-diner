# 《심야식당》 원작 조사

- 조사 기준일: 2026-11-07
- 목적: 심야식당 운영 웹게임의 세계관과 콘텐츠 기획 참고
- 상태: 공개 웹 자료를 이용한 기초 조사
- 범위: 출판사 공식 소개·목차, 작가 인터뷰, 원작 작품 사전, 영상화 공식 사이트

> 원작 31권 전체를 직접 열람한 전수조사가 아니다. 아래 목록은 전체 등장인물·음식·에피소드·결말의 완전한 목록이 아니다. 원작 사실, 영상판 정보, 게임화 해석을 구분하며, 웹에 공개되지 않은 세부 내용은 미확인으로 남긴다.

## 2. 식당과 영업 설정

- 도쿄 신주쿠 번화가 뒷골목의 작은 식당이다.
- 노렌에는 `めしや`(밥집)라고 적혀 있다.
- 자정부터 아침 7시 무렵까지 영업하므로 손님들이 심야식당이라고 부른다.
- 기본 메뉴는 돈지루(돼지고기 된장국) 정식과 맥주·소주·일본주다.
- 메뉴판에 없어도 재료가 있고 마스터가 만들 수 있으면 주문을 받는다.
- 마스터와 서로 다른 사정을 가진 손님들의 만남이 이야기의 중심이다.

출처: [원작 공식 소개][S1], [출판사 IP 소개][S3], [원작 작품 사전][S4].

작가는 자유 주문 설정이 앞으로 이야기를 확장하기 위한 전략이었다고 설명했다. 누구나 맛을 떠올리기 쉬운 음식을 선택한 것도 음식 지식보다 그 음식을 먹는 사람을 그리고 싶었기 때문이다.

출처: [작가 인터뷰 — 단골이 되고 싶은 가게][S5].

## 5. 서사 구조 분석

작가는 요리의 전문 지식보다 음식을 먹는 사람과 그 음식이 불러오는 과거를 그리는 작품이라고 설명한다.

출처: [작가 인터뷰][S5], [작가·뮤지컬 연출가 대담][S9].

다음은 그 발언과 확인한 소재를 바탕으로 한 기획 분석이며 공식 설정이 아니다.

| 요소 | 서사에서 기대할 수 있는 역할 |
| --- | --- |
| 손님의 주문 | 취향과 사정에 관한 첫 단서 |
| 조리·식사 | 대화나 회상이 시작되는 시간 |
| 단골의 반응 | 새로운 손님을 기존 공동체와 연결 |
| 같은 음식의 재등장 | 과거와 현재, 이전 방문과 이번 방문의 연결 |
| 익숙한 식당 | 손님의 변화를 비교하는 기준점 |
| 단편의 반복 | 새로운 이야기를 제공하며 단골에 대한 애착 축적 |

게임에서는 좋아하는 음식뿐 아니라 주문 이유, 함께 먹은 사람, 이전 방문 이후의 변화를 기록하는 방식을 검토할 수 있다.

## 6. 원작과 영상판 구분

### 확인한 영상화 범위

- 일본 드라마는 2009년부터 제작됐다.
- 기존 1~5부와 `Tokyo Stories` 계열이 있으며, 조사 기준일의 공식 사이트에는 6부도 확인된다.
- 일본 영화는 《심야식당》(2015), 《속·심야식당》(2016)이 있다.
- 한국·중국 리메이크는 일본 원작 및 일본 영상판과 별도로 구분한다.

출처: [시리즈 공식 아카이브][S10], [현행 공식 사이트][S11], [MBS 공식 소개][S12].

### 혼동 방지 기준

영상판의 배우 외형, 구체적인 사건·인물 관계를 원작 설정으로 바로 사용하지 않는다. 공식 영상판 사이트에서 소개하는 미치루·지에코·고구레·가타기리 등의 설명만으로 만화에서의 등장 여부나 동일 설정을 확정할 수 없다.

출처: [영상판 등장인물 소개][S10].

음식 자료도 다음 범위로 구분한다.

1. 만화 원작에 등장한 음식과 조리 묘사
2. 드라마·영화에서 채택하거나 각색한 음식
3. 영상 제작용 조리법과 별도 레시피 자료

이이지마 나미의 《심야식당 요리첩》은 조리 구현에 참고할 수 있는 별도 자료다. 원작 전체 메뉴 목록과 동일한 자료로 취급하지 않는다.

출처: [쇼가쿠칸 요리첩 소개][S13].

## 7. 게임화 제안 — 미확정

아래는 원작 사실이나 합의된 게임 사양이 아닌 초기 제안이다.

| 시스템 | 검토할 내용 |
| --- | --- |
| 영업 | 자정 개점, 새벽 시간 흐름, 아침 마감 |
| 주문 | 기본 메뉴와 식재료에 따른 특별 주문 |
| 손님 | 단골과 처음 온 손님을 섞어 방문 구성 |
| 취향 | 음식·양·간·곁들임·먹는 방식 |
| 관계 | 손님끼리의 친분·갈등·동반 방문 |
| 이야기 | 여러 차례 방문으로 나뉘는 짧은 사연 |
| 기록 | 음식 도감과 손님에 대한 기억 |
| 진행 | 새로운 음식·손님·재방문 이야기 해금 |

### 아직 결정하지 않은 기획

- 요리 조작, 식당 경영, 손님 이야기의 비중
- 아트 스타일과 화면 구성
- 하루의 길이, 실패·성공 조건, 경제 밸런스
- 재료 구매·재고·조리 시스템
- 원작 조사 내용을 실제 게임에 반영할 범위

### 현재 프로토타입과의 관계

프로토타입은 개점 → 손님 3명의 주문 처리 → 마감 → 다음 밤, 매출과 식사 수 기록, 브라우저 자동 저장을 지원한다. 현재 손님과 대사는 임시 창작 데이터이며 원작의 등장인물·에피소드를 구현한 것이 아니다.
