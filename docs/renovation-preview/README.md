# 50레벨 매장 개선 시안

이 폴더는 기존 게임과 연결되지 않은 **검토용 시안**입니다. `index.html`을 열어 레벨별 모습과 개선 연출을 확인할 수 있습니다. 실제 게임의 아이템 구매를 교체하거나 캐쉬를 차감하지 않습니다. 기존 조리·화구·주방 조작 이미지, 버튼, HUD, 엔진과 저장 데이터는 수정하지 않았습니다.

## 제안한 방식

- 개별 아이템 구매·배치 대신 **분위기 및 환경 개선** 섹션에서 내부 또는 외부 개보수를 선택합니다.
- Lv1~50마다 내부 1개, 외부 1개: 총 100개 선택지입니다. 각 구역의 이전 개선을 완료하고, 해당 플레이어 레벨과 캐쉬 조건을 충족해야 합니다.
- 캐쉬는 목표 이미지가 준비된 뒤 한 번 차감합니다. 촤라락 소리와 화면 전환 뒤 반짝임·짧은 완료음·분위기/환경 증가를 표시합니다. 부족한 캐쉬, 레벨 잠금, 중복 입력, 이미지 로딩 실패를 처리합니다.
- 내부와 외부는 독립적으로 진행합니다. 고레벨 플레이어는 밀린 개선을 순서대로 진행할 수 있습니다. 이미지 시안은 단계별 전체 배경 한 장을 사용하므로 같은 조명이나 가구를 두 번 겹쳐 그리지 않습니다.
- 실내 배경의 냉장고, 벽, 천장, 후드 주변, 수납장, 출입문, 카운터와 바닥까지 바뀝니다. 별도의 조리·냉장고 조작·화구 장면은 변경하지 않습니다.
- 외부는 노렌, 간판, 문/창, 외벽, 지붕/처마, 식재, 조명, 문턱과 앞길을 개선합니다. 같은 가게와 골목의 구도를 유지합니다.

## 이미지와 파일

- `assets/inside-00.webp` / `outside-00.webp`: 현행 매장 기준 모습.
- `assets/inside-01.webp`~`inside-50.webp`, `outside-01.webp`~`outside-50.webp`: 100개 개선 상태. 내부 1536×1024, 외부 940×1674.
- `inside-milestones.png`, `outside-milestones.png`: 현재, Lv10, 20, 30, 40, 50 비교.
- `inside-all-levels.png`, `outside-all-levels.png`: 전체 50단계 연락판.
- `catalog.json`, `catalog.csv`: 각 선택지의 필요 레벨, 비용, 증가 수치.
- `verification.json`: 실제 Chromium 시연 확인 결과.

전체 사진을 매 레벨마다 새로 생성한 것은 아닙니다. 현재 모습과 10레벨 간격의 주요 사진을 기준으로 구역별 개선을 합성한 50단계 **디자인 시안**입니다. 최종 게임 적용 시에는 손님 가림, 비/낮밤 효과, 화면 크롭을 실제 서비스 장면에서 추가 검토해야 합니다.

## 가격·보상 초안

내부 비용은 `(400 + 45×레벨 + 3×레벨²)`을 50단위로 반올림하고, 외부는 그 85%를 50단위로 반올림합니다. 내부는 기본 분위기 +2/환경 +1, 외부는 분위기 +1/환경 +2이며, 5레벨마다 +1, 10레벨마다 +2를 양쪽 보상에 더합니다. 두 보너스는 중복하지 않습니다. Lv1 내부 450/외부 400, Lv50 내부 10,150/외부 8,650 캐쉬입니다.

이는 제안 가격과 보상으로, 실제 과금·게임 경제에는 연결하지 않았습니다. 현행 엔진의 레벨 상한(34), 기존 꾸미기 구매/보유 이력과 분위기 레벨 조건은 시안 승인 후 별도 50레벨 마이그레이션 설계가 필요합니다. 기존 유료 구매가 있다면 이력을 보존하고 차액/보상 정책을 정해야 하며, 임의 삭제나 초기화를 하지 않습니다.

## 검증 범위

100개 선택지와 102개 이미지 존재/중복 여부, 전체 순차 구매, 필요 레벨/잔액 제한, 1회 차감, Lv50 종료를 자동 검증했습니다. Chromium에서 데스크톱·393×852 모바일, 연속 입력 차단, 이미지 실패 시 미차감, 캐쉬 부족, 효과음 생성, 반짝임/증가 수치, 모션 줄이기, 가로 넘침 없음도 확인했습니다. 효과음은 Web Audio로 만든 짧은 노이즈 스윕과 상승 벨 음이며, 녹음된 조리 효과음을 교체하지 않습니다.

이미지 생성 도구: `image_gen`. 기준은 기존 `room-bare-v19.webp`, `exterior-bare-v19.webp`입니다. 주요 10장의 새 시안만 생성했고, 개별 음식·인물·조리 사진은 생성하지 않았습니다. 생성 출처는 `provenance.json`에 기록했습니다.
